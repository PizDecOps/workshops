# 🔨 Git Deep Dive: От коммитов до магии

Добро пожаловать в материалы воркшопа по продвинутому использованию Git. Здесь мы разбираем не просто команды, а механику работы системы, чтобы вы могли уверенно выходить из любой ситуации.

---

## 📜 Программа обучения

1. **Внутреннее устройство:** Объекты, хеши и папка `.git`.
2. **Жизненный цикл файла:** Три состояния и магия индекса.
3. **Коммиты как искусство:** Атомарность и интерактивный `add -p`.
4. **Ветвление:** Почему ветка — это файл весом 41 байт.
5. **Merge vs Rebase:** Разбор на атомы.
6. **Контекст:** Продвинутый `Stash` и `Cherry-pick`.
7. **Машина времени:** `Reset` и спасительный `Reflog`.
8. **Хирургия истории:** Интерактивный Rebase (`squash`, `reword`).
9. **Автоматизация:** Git Hooks (Husky).
10. **Параллельные миры:** Git Worktrees.
